# 扫码顺序比对工具

扫码枪每扫一个条码，立即与 Excel 清单的**对应顺序**做比对：一致 → 记录日志（可开启提示音）；不一致 → 红色警示 + **声音报警**，且不推进序号，可重扫。

## 一、扫码枪怎么接入？（关键原理）

**芯片扫码枪几乎都支持出厂默认的“USB-HID 键盘模拟”模式**：插上（或用 USB 接收器/蓝牙）后，它就是一个键盘。扫一下 = 自动把条码字符“打”进当前获取焦点的输入框 + 自动按一下回车。所以本程序**不需要任何驱动、SDK、串口通信**，只要让界面上的输入框始终获得焦点即可，有线 / 2.4G 无线 / 蓝牙三种扫码枪通用。

| 类型 | 特点 | 建议 |
|---|---|---|
| USB 有线 | 即插即用，最便宜（约 ¥40–80） | ✅ 预算有限首选 |
| 2.4G 无线（带接收器） | 无线但即插即用，不用配对（约 ¥80–150） | ✅ 需要移动时首选 |
| 蓝牙 | 需配对、会休眠、首次连接慢 | 不推荐现场用 |

**购买时确认三点**：
1. 支持 HID 键盘模式（几乎全部支持，有的说明书叫“键鼠模式”/“KBW”）。
   - 可设置“回车后缀”（默认一般已开启；万一没有，用说明书里的配置码扫一下开启）。
3. 支持你要扫的条码类型（Code128 / EAN-13 / Code39 等，默认基本全开）。

**买回来后 1 分钟验证**：插上扫码枪 → 打开记事本 → 扫一下，能出现条码数字并换行，就说明一切正常，直接用本程序即可。

## 二、运行步骤

```bash
# 1. 安装依赖（仅需要 openpyxl）
pip install openpyxl

# 2. 启动
python barcode_checker.py
```

界面操作：
1.  “浏览…”选择 Excel → 选工作表 → 选比对列 → **加载数据**。
2.  输入框保持焦点，直接开始扫描。
3.  无扫码枪时可手动在输入框键入条码 + 回车，模拟扫码测试。

## 三、Excel 清单要求

- 第一行是表头（列名），从第 2 行起是**按顺序排列**的条码。
- 行号顺序即期望扫描顺序：第 1 枪必须扫到第 2 行的码，第 2 枪第 3 行……
- **条码列建议设为“文本”格式**：否则前导 0 会丢失、长数字会变成科学计数法，导致比对失败。（先选列 → 数据 → 分列，或直接设单元格格式 = 文本）
- 需要取某列（如“序号”）之外的列做比对？在“比对列”下拉框选其它表头即可。
- 公式单元格需要 Excel 保存过（有缓存值）才能读到。

## 四、报警与日志

- **报警音**：默认 3 声急促蜂鸣；把自定义的 `alarm.wav` 放到程序同目录会自动优先播放。
- **日志**：每次扫码实时追加写入 `logs/scan_日期时间.csv`（UTF-8 BOM，Excel 双击即可打开），
  记录 时间 / 结果（[OK] / [错误] / [跳过] / [忽略] / [超额]）。
- 提示“该码在清单第 N 位”：扫到错误码时，程序会指出它在清单里的正确位置，
  方便判断是拿错货还是顺序错了。


## 六、常见问题

1. **扫了没反应**：确认扫码枪已开启“回车后缀”；输入法切到**英文**（ENG）状态——
   中文输入法会把字母/数字组合吃掉或转成拼音上屏。（Ctrl+Shift / 按 Shift 切换英文）
2. **扫一下蹦出两条**：说明扫码枪配置了回车 + Tab 等多余后缀；翻说明书关闭。
3. **重复码误报**：同一码 0.5 秒内再次扫描会被自动忽略（防连发），日志记 [忽略]。
4. **Excel 数据有重复条码相邻？** 真实重复时两次扫描间隔 > 1 秒，不受防连发影响。
5. **想区分“扫码枪输入”和“键盘输入”？** 本项目采用最通用的键盘模式。如需串口隔离（USB-COM 虚拟串口模式），需要扫码枪切换模式并装驱动，本程序可后续扩展 `pyserial` 实现，一般无此必要。
