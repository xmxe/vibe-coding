# 三年级数学计算思维每日一练生成器

自动随机生成「三年级上册数学计算思维每日一练」练习册，并一键合并打印成 PDF。

## 项目功能
- 按照人教版三年级上册知识点，每天随机生成 4 类题目：
  - 口算题（20 道，含进退位加减、三位数加减、表内乘除、混合运算、同分母分数加减）
  - 列竖式计算（4 道，含三位数连续进退位、多位数乘一位数、两位数除以一位数）
  - 脱式计算（8 道，含无括号运算、含括号加减、含括号乘法等）
  - 解决问题（2 道，含两步加减、乘加/乘减、连乘、进一法、周长、归一问题，题目场景随机化）
- 把每天题目渲染成 A4 版式 HTML，自动调整各区块留白，保证单页打印不溢出
- 用 Playwright 将多天 HTML 逐个转 PDF，再用 pypdf 合并成一个完整 PDF

## 文件说明
- `main.py`：程序入口，输入天数 N 后自动生成 N 份 HTML 并合并成 PDF
- `math_generator.py`：题目数据生成器（各题型"池子"集中在对应区块，便于扩充）
- `html_template.py`：HTML/CSS 排版模板，负责把题目渲染成可打印的 A4 页面
- `html/`：生成的 HTML 练习册（运行时自动创建）
- `三年级口算练习册_全册.pdf`：最终合并生成的 PDF（运行时自动创建）

## 使用方法
1. 安装依赖：
   ```
   pip install playwright pypdf
   playwright install chromium
   ```
2. 运行：
   ```
   python main.py
   ```
3. 按提示输入天数（如 30），程序会自动生成 30 份 HTML 并合并为 `三年级口算练习册_全册.pdf`

## 依赖
- Python 3.x
- `playwright`（调用 Chromium 渲染 HTML 为 PDF）
- `pypdf`（合并多个 PDF 文件）
